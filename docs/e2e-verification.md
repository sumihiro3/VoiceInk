# 実機手動検証(e2e-verification)— 共通のテストケース

MacBook Pro(M1 Pro)で口述して確かめる項目の一覧。各リリースの requirements.md で「(手動検証必須)」と付記した AC は、`docs/releases/<release>/e2e-verification.md` にここから該当ケースを写し、実施のたびに記録する。合格基準は CLAUDE.md の「合格基準(暫定)」が正本(数字は最初の計測で見直す)。

## 何を見て・何を見ないか

- **見る**:実機の口述でしか分からない項目(文字が出るまでの時間、長い口述での認識時間、無音、言い直し、中止、録音停止から貼り付けまでの時間)
- **見ない**:ビルドが通るか、コードの静的な正しさ(`make build` とレビューで見る)

## 準備

1. Mac mini で `scripts/deploy-mbp.sh` を実行し、MacBook Pro の /Applications/VoiceInk.app を置き換える
2. MacBook Pro で、Whisper(large-v3-turbo)を選んだ Mode を使う。途中経過用モデルもダウンロードしておく
3. 試したら Mac mini からログを取る(`logs/` はコミットしない)

```bash
ssh mbp "log show --last 5m --info --predicate 'subsystem == \"com.prakashjoshipax.voiceink\"'" > logs/mbp-$(date +%H%M).log
```

## テストケース

- [ ] 短い発話:5秒程度の一文を話す
  - 期待:話し始めて2秒以内に文字が出る
- [ ] 長い口述:60秒以上話し続ける
  - 期待:1回の認識時間(os_log)が処理間隔(1秒)を超え続けない
- [ ] 英語混じり:「Claude CodeでGitHubのPRを確認」など
  - 期待:最終結果が、従来の録音後処理と同等の表記になる
- [ ] 無音:10秒黙る
  - 期待:文字が出ない
- [ ] 言い直し:途中で言い直す
  - 期待:確定部分が書き換わらない
- [ ] 途中で中止:Esc で録音をやめる
  - 期待:処理が残らず、次の録音がすぐ始められる

## 計測するもの

- 1回の認識時間と、そのときの音声の長さ(os_log から取る)
- 話し始めてから最初の文字が出るまでの時間
- 録音停止から貼り付けまでの時間(従来の Whisper より遅くなっていないか)
- 録音中の CPU と GPU の使用率(アクティビティモニタ)
